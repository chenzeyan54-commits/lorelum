---
title: Alpha 兼容性
description: Lorelum 在版本演进期间的兼容性说明。
icon: FlaskConical
---

Lorelum 处于公开 alpha 阶段。版本可能改变 CLI 行为、配置、文件格式或检索结果，暂不承诺自动迁移。升级共享环境前，请阅读对应版本的 release note。

预编译发行包支持 macOS Apple Silicon、Linux x64 和 Windows x64。macOS 是 Lorelum 优先适配、验证更充分的发布平台；Linux x64 和 Windows x64 为尽力支持，不保证在所有发行版、系统构建、硬件和本地安全策略下的兼容性与性能。需要复现结果时，同时固定 CLI 和 Pack 版本。

需要稳定复现时，固定 CLI 和 Pack 版本。使用新版本或不熟悉的 Pack 前，先在隔离 Store 中试用。

安装时请阅读对应版本的 release note，其中会记录发行包、校验和、平台支持、破坏性变更与已知限制。
